# Spread

Spread is a generative tree screen saver for macOS. It was originally created by Tom Theisen and ported to Cocoa by Kevin Wojniak.

This version updates the original project for current macOS releases and provides separate Apple silicon and Intel builds.

## Build

```sh
./build.sh arm64
./build.sh x86_64
```

The screen saver bundles and ZIP archives are written to `build/<architecture>/`.

## Original release

Spread 1.0.1 was released on February 28, 2012.

- Original version by Tom Theisen — <http://tomtheisen.com/spread/>
- Cocoa screen saver port by Kevin Wojniak — <http://kainjow.com>
